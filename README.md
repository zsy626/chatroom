# 网络聊天室 - 改进版

计算机网络大作业的聊天室。**源项目 `PycharmProjects\Chatroom` 没动**,这里是改进版,放在桌面 `Chatroom_v2`。

## 文件说明

| 文件 | 说明 |
|---|---|
| `client.py` | 改进版客户端 |
| `server.py` | 服务端(**支持文件转发**,需要用它跑) |

> ⚠️ 基础聊天用你原来的 `server.py` 也能跑,但**文件传输必须用这里的 `server.py`**(原来的不转发 FILE 消息)。

## 功能一览

1. 登录、群聊、`@私聊`
2. 在线用户列表(点人自动 `@TA`)
3. **消息气泡**:自己靠右蓝色,别人靠左灰色
4. **@提及高亮**:别人 `@你` 时整条变黄 + 提示音
5. **文件/图片传输**:分片发送 → 序号重组 → MD5 校验;PNG/GIF 图片自动内联显示
6. 时间戳 + 连接状态指示 + 断开按钮 + 状态栏(在线人数/当前用户)
7. 服务器 IP/端口可配置

## 运行方法

1. 先跑服务端:`python server.py`
2. 再开多个客户端:`python client.py`
3. 填昵称 → 服务器 IP → 端口(8888)→ 连接。

> 多机测试把「服务器」填服务端机器的局域网 IP;本机测试填 `127.0.0.1`。连不上就查服务端防火墙是否放行 8888。

## 聊天用法

- 直接输入回车 → **群聊**(气泡)。
- `@用户名 内容` 回车 → **私聊**。
- 点右侧在线列表里的人 → 自动填 `@TA `。
- **发文件**:点「发送文件」→ 选文件 → 群发所有人;若先在输入框填了 `@用户名` 再点「发送文件」→ 私发给 TA。
- 收到的文件保存在 `received_files/` 目录,PNG/GIF 会直接显示在聊天框里。

## 协议格式(与 server.py 一致)

```
LOGIN|昵称
GROUP|昵称|消息
PRIVATE|发送者|接收者|消息
FILE|发送者|接收者|文件名|分片总数|md5
FILEDATA|发送者|接收者|md5|分片序号|base64数据
USERS|昵称1|昵称2|...      (服务端下发)
ERROR|提示                 (服务端下发)
NOTICE|提示                (服务端下发)
```

## 设计要点(报告可写)

- **粘包处理**:服务端/客户端都按 `\n` 缓冲拆包,解决 TCP 流式传输的边界问题。
- **文件分片与重组**:48KB 一片,`seq` 序号标识,接收端按序重组;`md5` 既做传输标识也做完整性校验。
- **群发/私发**:`receiver=ALL` 走广播(排除发送者),否则定向转发。

## 已知限制

- 消息内容不能含 `|` 或换行(协议用 `|` 分隔、`\n` 结尾)。
- 输入框为单行(回车即发送),要支持多行/富文本需改协议。
- 内联图片只支持 PNG/GIF(tk 原生);JPEG 需要 Pillow,否则只保存不显示。
- 大文件传输时,发送端和服务端会逐片转发,超大文件(几百 MB)会慢,建议演示用几 MB 以内的文件。
